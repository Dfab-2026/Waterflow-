Reset water records?

This clears the stored history and resets cumulative litres and pulse counts for all eight pipes.

If the ESP32 is offline, the command will stay queued and run when the device reconnects. Export your records first if you need a copy.

 TEMPORARY TEST CONTROL

Clear all water data?

This immediately deletes all stored water readings, history and reset records for this dashboard. Charts and totals will start empty.

The ESP32 counters will reset when it receives the command. If it is offline, the dashboard will wait for its acknowledgement before showing live readings again.

Download a CSV first if you need the existing records.
